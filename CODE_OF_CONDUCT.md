# Code of Conduct

People run BananaChat on their own servers, often for other people. Please
keep that in mind in issues, pull requests and discussions, because someone
reading a thread may be deciding whether to trust this software with their
data.

We expect you to:

- Discuss the change, not the person who proposed it.
- Say what you tested and what you didn't.
- Leave other people's data out of reports, and reproduce bugs with content
  you're free to publish.
- Accept that a maintainer may decline a feature without a long explanation.

Harassment, personal attacks, sustained disruption, publishing someone's
private information and posting data from someone else's installation are not
acceptable.

Maintainers may edit or hide comments, lock threads or block accounts when a
discussion is no longer about the software, and they'll explain why.

To report a problem, contact
[Luca Zani (OverloadedTech)](https://github.com/OverloadedTech) using the
contact details on their GitHub profile. Please don't report security
vulnerabilities this way. Follow [SECURITY.md](SECURITY.md) instead.
