{# Setup guide #}
Setup Guide
  1. Click Register & Get Token above and copy the one-time token.
  2. On the PC that will run inference, clone / copy the worker/ directory.
  3. Install optional dependencies: pip install nvidia-ml-py3 psutil
  4. Set environment variables (or create a .env file): 
    BC_SERVER_URL={{ request.host_url.rstrip('/') }}
BC_WORKER_TOKEN=<paste token here>
BC_WORKER_NAME=My Gaming PC
  5. Test manually: python bananachat_worker.py run
  6. Install as a service (runs on login / at boot):
    Linux: python bananachat_worker.py install
    Windows: python bananachat_worker.py install (run as Administrator)
  7. Enable worker dispatch on the server by setting BC_WORKERS_ENABLED=1 and restarting.
