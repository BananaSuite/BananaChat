Export

Downloads a .tar.gz archive containing a consistent snapshot of the entire database: all users, chats, API tokens, settings, model catalog, usage history, and audit logs.

Ollama model weights are not included. After importing, Admin → Models offers to download the saved models or leave them for later. User passwords and API tokens are stored as hashes and cannot be reversed.

Restore

Restore from the server during a maintenance window. The command stops every application process, creates a rollback package, and checks the restored service before reopening it. A failed import restores the previous installation.

For an installation package created with bananachat backup or migrate:

sudo bananachat restore /root/ai-backup.tar.gz

For the database export above or an older raw database:

sudo bananachat restore --legacy-database /root/bananachat_export.tar.gz

Database exports contain users, chats and model settings. Preserve session keys, uploaded audio, configuration and any external files separately. A complete installation package includes managed data and configuration; use --exclude-model-weights when creating a package if models should be downloaded again after recovery. Review model downloads in Admin → Models after restoring; you can select Not now.

If maintenance is interrupted, run sudo bananachat recover before retrying.
