{{ icon("code") }}Git repositories

{{ csrf() }}

Tasks can start from a public repository: the web server downloads its source archive over HTTPS from an allowed host (never from an address people type, never a private network address) and the runner unpacks it into the sandbox. With Git in the sandbox image, people can download the agent's changes as a .patch. No credentials are used, so only public repositories work; downloads cost no tokens.
