{{ icon("chevron-down") }}How limits work
  • Request rates apply per account within each service. All API keys and the playground share the API allowance; chat and agents have separate allowances. All configured rate rules apply together.
  • 5-hour tokens cover prompt and response usage. The first request opens a 5-hour window; the allowance resets when it ends.
  • Weekly tokens are off by default. When enabled, the first request opens a 7-day window. Exhausted allowances become available at reset.
  • Model rules can add separate limits and multiply service token usage by a model's weight. Configure them under Models.

Account overrides replace service defaults. Otherwise, tier and demand adjustments apply before music bonuses and grants. Custom limits are never reduced by demand. {{ custom_count }} account(s) have custom limits, exemptions or queue settings; {{ grant_count }} grant(s) are active.
