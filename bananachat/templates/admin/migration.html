Backups

Run these on the server. The site pauses for a moment while a backup is made.

Full backup, with model files
{{ command("sudo bananachat backup") }}
Backup without model files
{{ command("sudo bananachat backup --exclude-model-weights --output /root/chat-data.tar.gz") }}
Restore a backup
{{ command("sudo bananachat restore /root/chat-data.tar.gz") }}

For encrypted, scheduled backups to a private GitHub or Forgejo repository, run sudo bananachat backups configure, then sudo bananachat backups enable. See docs/backups.md. Keep an offline copy of the recovery key. After a restore without model files, Models offers to download them again.

Database export

A copy of the database ({{ database_size | filesize if database_size is not none else "size unknown" }}, schema version {{ schema_version }}) for moving an older installation to a new managed server:

{{ command("sudo bananachat restore --legacy-database /root/bananachat_export.tar.gz") }}
{{ icon("alert") }}

The file contains every account, password hash and chat. Keep it as secure as the server and delete it when you are done.

The export does not include model files, uploaded audio, the secret key or the server configuration. Without the secret key, accounts with two-step verification sign in with a recovery code and set it up again.
