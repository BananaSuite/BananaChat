{{ icon("chevron-down") }}Set up a worker PC
  1. Register the worker above and copy its token.
  2. On the PC, install Ollama and pull the models it should serve, for example ollama pull qwen3:4b. Use the same model names as this server.
  3. Copy the worker/ folder of this server’s source code to the PC (needs Python 3.9 or newer).
  4. Run python bananachat_worker.py install in that folder. It creates the settings file and a background service.
  5. Edit the settings file (~/.config/bananachat-worker.env, or %APPDATA%\BananaChat\bananachat-worker.env on Windows): 
    BC_SERVER_URL={{ server_url }}
BC_WORKER_TOKEN=<the token>
BC_WORKER_NAME=My gaming PC
  6. Start it with python bananachat_worker.py start and watch it appear here as online.

The worker steps aside while its owner plays games. See docs/workers.md.
