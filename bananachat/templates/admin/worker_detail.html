SSH, VNC and RDP from your computer

Download the connect helper (one Python file, standard library only, for Linux, macOS and Windows) and create an access key on the Workers page. Then:

python bananachat_connect.py login {{ server_url }}
python bananachat_connect.py list

Each worker has an address in the virtual network {{ data.subnet }} that only the helper knows; it works wherever the worker is. The commands for this worker appear above once it reports what it allows.
