{# API Quota Defaults #}
API Credit Defaults
Applied when a new user's quota row is created. Change individual users on the Users page. 1 credit = 1,000 tokens (input + output). Admins always have unlimited credits.
When disabled, users only get regular credits. The slow credit pool is removed globally. Requests beyond regular credits are rejected outright instead of being processed at low priority.
{# Quota Request Auto Approval #}
Quota Request Auto Approval
Disabled by default. Eligible requests must preserve both current allocations, increase at least one, and stay at or below both limits. One-day requests always await administrator review.
{# API Rate Limit #}
API Rate Limit (RPM)
Per-client IP sliding window. Set to 0 to disable RPM limiting for the API. Default: 60.
{# Chat Rate Limit #}
Chat Rate Limit (RPM)
Per-user sliding window. Leave blank or 0 for unlimited. Admins bypass this limit.
{# Chat Daily Limits #}
Chat Daily Credit Limits
When enabled, chat usage is tracked in a separate credit pool. Users who exhaust their chat credits are blocked from sending new messages until midnight UTC. When disabled, chat is unlimited (default).
Chat and API credit pools are completely separate: chat usage never counts against API quota and vice versa. The slow credits tier is controlled by the global toggle above.
{# Music Bonus Mode #}
Music Program Bonus
How opted-in users' quotas are boosted. The bonus applies to both API and chat pools (when enabled). The multiplier value is set on the Music Program page.
Fixed bonus values are only used when "Fixed bonus" mode is selected. In multiplier mode, these are ignored.
